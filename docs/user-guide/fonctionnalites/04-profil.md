# Fonctionnalité Utilisateur : Consultation du profil

## Présentation

La page « Mon profil » permet à l'utilisateur de consulter les informations associées à son compte et son activité dans Doc2Quiz.

## Accéder au profil

1. Depuis la page d'accueil, cliquer sur le bouton « Mon profil ».
2. La page du profil s'affiche.
3. Pour revenir à la page principale, cliquer sur « Revenir au générateur ».

## Informations personnelles

La partie supérieure du profil affiche :

- les initiales de l'utilisateur ;
- son nom ;
- sa formation ou son rôle ;
- sa date d'inscription ;
- le nombre de sessions réalisées.

> Il est possible de modifier des informations de son profil en cliquant sur le bouton "**Modifier**".

## Compétences par domaine

La section « Compétences par domaine » présente les résultats de l'utilisateur pour les différents domaines étudiés.

Pour chaque domaine, le profil affiche :

- le nom du domaine ;
- un score en pourcentage ;
- une barre de progression correspondant à ce score.

> Ces indicateurs permettent de repérer rapidement les domaines dans lesquels l'utilisateur a obtenu les meilleurs résultats et ceux qui nécessitent davantage de révision.

## Zone de gestion du profil

Une zone destiné à la gestion des données propose les actions suivantes :

- supprimer l'historique des sessions ;
- supprimer définitivement le profil et les données associés au compte.
