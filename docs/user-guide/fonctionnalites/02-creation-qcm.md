# Fonctionnalités Utilisateur : Création d'un QCM

Cette fonctionnalité permet de transformer automatiquement un support de cours en un questionnaire à choix multiples personnalisable.

---

## 1. Import du document & Paramétrage

1. Rendez-vous dans la section **« Créer un QCM »**.
2. **Déposez votre fichier :**
   - Glissez-déposez votre document (`.pdf` ou `.md`) dans la zone dédiée, ou
   - Cliquez sur la zone d'import pour sélectionner le fichier depuis votre ordinateur.
3. **Sélectionnez le niveau :** Choisissez le niveau d'enseignement ciblé dans le menu déroulant (ex. *4ème, Seconde, BUT...*).
4. **Sélectionnez le type de QCM** Choississez entre Question de cours ou Exercices ou les 2 à la fois.
5. Cliquez sur **« Générer le QCM »**.

> **Note :** Pendant le traitement de votre document, une phase de chargement s'affiche. La durée de génération dépend de la taille de votre fichier.

---

## 2. Édition et personnalisation du QCM

Une fois le QCM généré, vous accédez à l'interface de révision :

* **Ajuster une question via l'IA :** Saisissez un commentaire textuel sous la question concernée pour demander une modification précise (ex. *« Rends la question plus simple »* ou *« Reformule l'option B »*).
* **Supprimer une question :** Cliquez sur l'icône de corbeille associée à une question pour la retirer du questionnaire.
* **Supprimer le QCM complet :** Si le résultat ne vous convient pas, vous pouvez annuler la création et supprimer l'intégralité du QCM.

> **Attention :** La suppression d'une question ou du QCM complet est définitive.

---

## 3. Validation et Export

Une fois les vérifications terminées, vous devez **valider le QCM** pour l'enregistrer.

Vous pouvez également exporter directement votre questionnaire sous deux formats :
* **Export PDF :** Pour une impression papier ou une distribution directe.
* **Export GIFT :** Pour une importation facile dans d'autres plateformes d'apprentissage (comme Moodle).

Si vous êtes étudiant, vous pouvez également vous **entrainez** dessus (rubrique *Entraînement*)

---

## 4. Conservation

Après validation, votre QCM est automatiquement conservé et accessible dans votre **Historique** (rubrique *Profil*).
