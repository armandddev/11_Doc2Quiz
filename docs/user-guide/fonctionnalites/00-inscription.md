# Fonctionnalité Utilisateur : Création d'un compte

## Présentation

La création de compte permet à un utilisateur ne possédant pas de compte d'accéder à un formulaire permettant de s'inscrire pour accéder aux fonctionnalités qui seront associées prochainement

## Créer un compte

1. Saisir un nom ainsi qu'un prénom 

2. Saisir une adresse e-mail 
> Note : L'adresse e-mail ne doit pas être déjà utilisée sur un autre compte
3. Saisir un mot de passe 
> Note : Le mot de passe doit contenir au minimum 8 caractères 
4. Valider le formulaire d'inscription.

Si les informations sont correctes, le compte est créé, l'utilisateur peut donc se connecter avec ses identifiants, voir  **[01-inscription.md](../fonctionnalites/01-connexion_compte.md)**
